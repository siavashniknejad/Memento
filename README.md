# Memento

A self-built spaced-repetition flashcard app (PWA).

## Structure

- `frontend/` - client PWA (HTML/CSS/JS, manifest, service worker)
- `backend/` - Node.js + Express + PostgreSQL API server
- `docs/` - project documentation

## Live

https://memento.novinapp.net

## Backend setup

cd backend
npm install
cp .env.example .env
node server.js
